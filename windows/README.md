# modlink — Windows

Панель управления пулом LTE-модемов: каждый модем становится отдельным
HTTP+SOCKS5 прокси на своём порту, с логином, паролем и кнопкой смены IP.

Нативное Windows-приложение на C. Ни Python, ни браузера, ни установки —
один `.exe`.

```
Клиент ──HTTP/SOCKS5──▶ modlink :ПОРТ ──▶ 3proxy (auto) ──▶ LAN IP модема ──▶ LTE
                                                             │
                                          Huawei HiLink ◀────┘  (реконнект / ребут)
```

---

## Что изменилось против Python-версии

| | Было | Стало |
|---|---|---|
| Прокси-движок | sing-box (~30 МБ) | 3proxy `auto` (~1.5 МБ, вшит в exe) |
| Логин | `modem{N}`, только чтение | редактируемый |
| Порт | `БАЗА + индекс*2`, пересчитывался | редактируемый, хранится |
| LAN IP (bind) | `192.168.{N}.100` хардкод | редактируемый |
| IP модема | `192.168.{N}.1` хардкод | редактируемый |
| Вёрстка | фиксированная таблица | 3 режима по ширине окна |
| TLS-значок | горел, но TLS не было | убран |
| Конфиг | `modems.conf` | `config.json` (старый импортируется) |

### Две мины, которые чинит этот порт

**Порты уезжали.** В Python порт считался как `base + i*2`, где `i` — индекс в
списке, *отсортированном по N*. Добавление модема с меньшим N сдвигало порты
всех остальных, и уже выданные клиентам строки `IP:PORT:LOGIN:PASS` молча
переставали работать. Здесь порт — обычное сохранённое поле; ничто не
пересчитывается само.

**«TLS ON» был фикцией.** sing-box `mixed` inbound не поддерживает TLS — это
признано прямо в комментарии исходника, при этом панель рисовала зелёный
значок, а вся машинерия генерации сертификата делала файл, который никто не
читал. Значка больше нет.

## Сборка

### Вариант 1 — не собирать вообще (рекомендуется)

Пуш в `main` → GitHub Actions собирает `modlink.exe` → вкладка **Actions** →
последний запуск → артефакт **modlink-windows-x64**. Компилятор не нужен.

### Вариант 2 — локально

Нужен [Visual Studio Build Tools](https://visualstudio.microsoft.com/downloads/)
с workload «Desktop development with C++».

```bat
build.bat
```

Скрипт сам скачает 3proxy при первом запуске и положит `modlink.exe` в `build\`.

### Вариант 3 — проверка сборки с macOS/Linux

```bash
ZIG=/path/to/zig ./build-zig.sh
```

Кросс-компиляция через zig. Проверяет, что код собирается и линкуется под
Windows; **запустить** результат так нельзя, и ресурсы (вшитый 3proxy) этим
путём не встраиваются — для рабочего бинарника нужен вариант 1 или 2.

## Файлы на диске

```
%ProgramData%\modlink\
  config.json              настройки и список модемов
  3proxy.cfg               генерируется, править бесполезно — перезапишется
  bin\3proxy.exe           распаковывается из ресурса при первом запуске
  logs\
    modlink.log            лог приложения
    3proxy.log             лог прокси (ротация 7 дней)
    modem<id>_reconnect.txt  история реконнектов (ротация на 5 МБ)
```

---

## Поля в таблице

| Поле | Что это | Куда идёт |
|---|---|---|
| ☑ | модем включён | пропуск строки при генерации |
| Имя | произвольная метка | только UI |
| Логин | имя пользователя прокси | `users <логин>:CL:<пароль>` |
| Пароль | пароль прокси | там же, `↺` генерирует новый |
| Порт | порт прокси | `auto -p<порт>` |
| LAN IP (-e) | адрес интерфейса модема на этом хосте | `auto -e<ip>` ← **это и привязывает трафик к модему** |
| IP модема | веб-морда Huawei | HiLink API: реконнект, ребут, тест |
| Рек. порт | порт триггера реконнекта | `GET http://<ip>:<порт>/reconnect` |
| Инт | автореконнект, минут (0 = выкл) | таймер внутри приложения |

Кнопки строки: **Test** (внешний IP через этот прокси + доступность HiLink),
**⟳** реконнект, **↻** ребут модема, **≡** лог реконнектов, **✕** удалить.

## Адаптивная вёрстка

Ширина окна выбирает режим, строки перестраиваются сами:

| Ширина | Режим | Строка модема |
|---|---|---|
| ≥ 1150 dp | широкий | одна линия, шапка колонок |
| ≥ 880 dp | средний | две линии |
| < 880 dp | карточка | четыре линии |

Ширины полей раздаёт flex-распределитель (`flex_apply` в `ui_theme.c`):
у каждой ячейки минимум и вес, остаток делится по весам. DPI учитывается,
переезд на другой монитор пересобирает шрифты через `WM_DPICHANGED`.

## Генерируемый 3proxy.cfg

```
auth strong
users "modem101:CL:te5xg83ted" "modem102:CL:v4yeyzh43n"

flush
allow modem101
auto -p15000 -i0.0.0.0 -e192.168.101.100 -olSO_EXCLUSIVEADDRUSE

flush
allow modem102
auto -p15002 -i0.0.0.0 -e192.168.102.100 -olSO_EXCLUSIVEADDRUSE
```

`auto` (появился в 3proxy 0.9.5) сам определяет HTTP CONNECT это или SOCKS5 —
один порт на оба протокола, как `mixed` у sing-box. `flush` перед каждым
сервисом сбрасывает накопленный ACL, поэтому модем не может уйти через чужой
интерфейс.

3proxy запускается в Job Object с `KILL_ON_JOB_CLOSE` — он гарантированно
умирает вместе с панелью, даже при жёстком её убийстве. Python-версия для
этого звала `taskkill /F /IM` и всё равно оставляла сирот.
