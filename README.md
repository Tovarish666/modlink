# modlink

Панель управления пулом LTE-модемов под Windows. Каждый модем становится
отдельным HTTP+SOCKS5 прокси на своём порту — со своим логином, паролем,
кнопкой смены IP и ребута.

Один `.exe`. Интерфейс — HTML/CSS в окне через **WebView2** (движок уже стоит
на всех Windows 10/11, ставить нечего), логика — нативный C. Ни Python, ни
установщика, ни браузера.

```
Клиент ──HTTP/SOCKS5──▶ :ПОРТ ──▶ 3proxy (auto) ──▶ LAN IP модема ──▶ LTE ──▶ интернет
                                                      │
                             Huawei HiLink API ◀──────┘   реконнект · ребут · тест IP
```

Данные приложения лежат в папке пользователя:
`%LOCALAPPDATA%\modlink` (`C:\Users\<user>\AppData\Local\modlink`) — конфиг,
распакованный 3proxy и логи. Никаких файлов в корне диска.

## Скачать

**Actions → последний зелёный запуск → артефакт `modlink-windows-x64`.**

Компилятор не нужен: CI собирает `.exe` на каждый пуш. Внутри уже лежит
3proxy — распаковывается сам при первом запуске.

## Быстрый старт

1. Запусти `modlink.exe`. При первом старте список пуст.
2. Вверху во вкладке **Сервер** заполни **Основную сеть**: IP этого хоста
   (адрес ПК в основной сети — на нём слушают прокси), внешний IP (для строк,
   что раздаёшь клиентам) и базовый порт.
3. **+ Модем** — добавит строку с автоматически предложенными портом, паролем и
   адресами вида `192.168.N.x`. Правь прямо в строке; «ещё» (шеврон) открывает
   LAN IP модема (bind, `-e`), порт реконнекта, авто-реконнект и ребут.
4. **Применить** — генерируется конфиг и стартует 3proxy.
5. **Test** на строке — покажет внешний IP через этот модем. Разные IP на разных
   строках означают, что привязка к интерфейсам работает.
6. **Копировать** — положит в буфер строку `IP:PORT:LOGIN:PASS`, готовую клиенту.

## Вкладки

- **Сервер** — то, что описано выше: пул модемов, 3proxy, реконнект/ребут.
- **Адаптеры** — в работе. Сюда переедет механизм виртуальных интерфейсов
  (Ethernet N, состояние «Сеть N», маскировка под Remote NDIS).

## Сборка вручную

Нужны «Visual Studio Build Tools» (бесплатные, workload «Desktop development
with C++»). Заголовок `WebView2.h` тянется через nuget автоматически; загрузчик
WebView2 встроен в `third_party/webview/webview.h`, отдельная `.dll`/`.lib` не
нужна.

```
build.bat
```

Результат — `build\modlink.exe`.

## Что внутри

| Файл                | Роль                                                        |
|---------------------|-------------------------------------------------------------|
| `app/host.cc`       | WebView2-хост: одно окно = один WebView, мост JS ⇄ C         |
| `app/ui.html`       | весь интерфейс (HTML/CSS/JS), встраивается ресурсом          |
| `src/bridge.c`      | мост: серверные операции → JSON для UI                       |
| `src/config.c`      | модель и `config.json` (каждое поле модема хранится, не выводится из N) |
| `src/proxy3.c`      | генерация конфига 3proxy и запуск дочернего процесса         |
| `src/net.c`         | HTTP через WinHTTP (TLS и прокси нативно)                    |
| `src/hilink.c`      | Huawei HiLink API — реконнект, ребут, статус                 |
| `src/reconn.c`      | авто-реконнект по интервалу + свой HTTP-эндпоинт             |

Третьи компоненты и их лицензии — в `THIRD-PARTY.txt`.
